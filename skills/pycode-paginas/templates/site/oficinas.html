Uma ordem que funciona para quem está começando

As oficinas são independentes, mas algumas ficam mais fáceis depois de outras. Esta é a sequência que recomendamos quando alguém pergunta por onde começar.

  1. Git para trabalhar em equipe, porque todas as outras usam um repositório.
  2. Como funciona uma API, que apresenta o caminho de uma requisição.
  3. Banco de dados sem mistério, para guardar o que a API recebe.
  4. Testes automáticos, que protegem tudo o que veio antes.

Se você já conhece uma parte, pode pular direto para a próxima. Deixe o seu e-mail e avisamos quando abrir a próxima turma.
