O que acontece nos 38 milissegundos entre o clique e a lista na tela

No primeiro encontro, você abre as ferramentas do navegador e mede cada fase de uma requisição. Esta é uma medição de exemplo em uma rede doméstica; cada conexão terá números próprios.

0 ms38 ms
  1. 3 msEndereçoO navegador descobre o IP do servidor.
  2. 6 msConexãoOs dois lados combinam por onde conversar.
  3. 8 msSegurançaA conversa passa a ser criptografada.
  4. 15 msServidorO código busca os livros e monta a resposta.
  5. 6 msDownloadOs bytes chegam e viram lista.

Quatro encontros, e cada um acrescenta uma peça ao mesmo projeto

O projeto começa no primeiro dia e cresce até virar uma API documentada e testada. Nada fica solto para depois.

Programa · 4 encontros · 8 horas
  1. 01

    O pedido

    Você lê uma requisição linha por linha e entende método, caminho, cabeçalhos e corpo.

    Tarefa: capturar três requisições de sites que você usa.
  2. 02

    O servidor

    Escrevemos juntos um servidor pequeno em Python que recebe o pedido e decide o que responder.

    Tarefa: acrescentar uma rota nova ao servidor.
  3. 03

    Os dados

    O servidor passa a consultar uma lista de livros, devolve JSON e trata erros com os códigos certos.

    Tarefa: responder 404 quando o livro não existir.
  4. 04

    O contrato

    Documentamos a API, escrevemos testes automáticos e publicamos o projeto no seu GitHub.

    Tarefa: pedir a uma pessoa da turma que use a sua API.

Cada encontro termina com uma tarefa de vinte minutos, revisada no começo do encontro seguinte.

O mesmo livro em três formatos, medido em bytes

No terceiro encontro, a API aprende a responder em JSON. Comparar com XML e HTML ajuda a entender por que esse formato virou o padrão das APIs: carrega os mesmos dados com menos texto ao redor.

Perguntas antes de começar

Se a sua dúvida não estiver aqui, escreva pelo site do estúdio e respondemos antes da próxima turma.

Preciso saber programar?

Ajuda conhecer o básico de Python, como variáveis, funções e listas. Os trechos novos são escritos em conjunto, com a explicação de cada linha.

Os encontros ficam gravados?

Sim. A gravação de cada encontro fica disponível no dia seguinte, junto com o roteiro escrito.

Que programas vou usar?

Um navegador atualizado, o Python 3.10 ou mais recente e o editor de código que você preferir. Todos são gratuitos.

Quanto tempo preciso reservar por semana?

As duas horas do encontro e cerca de vinte minutos para a tarefa, que é curta para caber na semana.

Dá para acompanhar pelo celular?

Dá para assistir, mas a parte prática pede um computador, porque você vai escrever e rodar código durante o encontro.
