Salva este carrossel pra ter os cinco módulos à mão quando começar o próximo script.

Antes de procurar um pacote no pip, eu confiro se a biblioteca padrão do Python já resolve. O pathlib cuida de caminhos de arquivo, o Counter do collections conta itens, o datetime faz conta com datas, o json lê e escreve o formato das APIs e o statistics calcula média e mediana. Os cinco já vêm instalados com o Python.

Os trechos das cartas rodam no terminal do Python, e a saída mostrada em cada uma é a saída real. Um deles, numa linha:
from collections import Counter; print(Counter("banana").most_common(2))
