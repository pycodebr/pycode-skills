Testar o próprio código tem cinco níveis: clicar em tudo, conferir com print, escrever assert, organizar os testes no pytest e rodar tudo sozinho a cada envio com integração contínua, a CI. Cada nível pede só um passo a mais que o anterior, e dá pra subir um degrau por projeto.

O assert do nível 3, pra testar no terminal do Python:
def media(n): return sum(n) / len(n)
assert media([8, 10]) == 9
