Antes de começar

Uma API é um combinado entre dois programas: um faz um pedido num formato conhecido e o outro responde com dados ou com um erro que explica o que faltou.

O que é um endpoint
É o endereço de um recurso, como /alunos/42. O método (GET, POST) diz o que você quer fazer com ele.
Por que a resposta tem um código
O código (200, 404, 500) resume o resultado antes de você ler o corpo da resposta.

Tarefas desta semana

  • Ler a seção sobre métodos HTTP
  • Fazer três requisições no terminal
  • Anotar os códigos de resposta que apareceram

Uma folha clara e um único azul

O azul é a única cor estrutural: links, botão principal e item ativo. Os adesivos coloridos (amarelo, verde, rosa, azul-claro e laranja) aparecem só em etiquetas, ícones e capas, nunca para organizar a página.

Cada pedido para uma API começa com um método. Ele diz ao servidor se você quer ler, criar, alterar ou remover alguma coisa. Os quatro abaixo resolvem quase todos os casos do dia a dia.

Dica: no terminal, curl -X POST troca o método do pedido.
