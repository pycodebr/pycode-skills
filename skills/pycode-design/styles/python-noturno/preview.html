Use with e esqueça o close()

O bloco with fecha o arquivo mesmo quando acontece um erro no meio da leitura. É o jeito que você vai encontrar em quase todo código de produção.

with open("dados.txt", encoding="utf-8") as arquivo:
    conteudo = arquivo.read()

with fecha o arquivo por você

Mesmo quando a leitura quebra no meio, o arquivo é fechado ao sair do bloco.

with open("dados.txt") as f:
    texto = f.read()
# aqui o arquivo já está fechado
print(f.closed)  # True
